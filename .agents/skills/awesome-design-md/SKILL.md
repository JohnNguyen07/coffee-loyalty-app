## How to Use in Projects

1. **Choose a Brand Theme**:
   When asked to style the application like a specific brand (e.g. Starbucks or Linear), open its `DESIGN.md`.
2. **Apply Design Tokens**:
   Extract exact hex codes, CSS variables, typography pairings, border radii, box-shadow elevations, and spacing rhythms.
3. **Copy to Project Root (Optional)**:
   You can copy the chosen brand's `DESIGN.md` into `coffee-app/DESIGN.md` so all AI agents automatically generate UI consistent with that brand:
   ```bash
   cp d:/COFFEE/awesome-design-md/design-md/starbucks/DESIGN.md d:/COFFEE/coffee-app/DESIGN.md
   ```
